# 🚀 GenLab Streamlit Cloud Deployment Guide

Follow these quick steps to host your **GenLab** playground live on **Streamlit Community Cloud** for free:

1. **Push to GitHub**:
   Create a new repository and upload the contents of the `genlab/` folder directly to the root of that repository.

2. **Deploy on Streamlit**:
   - Navigate to [share.streamlit.io](https://share.streamlit.io/).
   - Click **Deploy an app**.
   - Choose your GitHub repository, main branch, and select `app.py` as your main entry point.

3. **Launch**:
   Click **Deploy!** Streamlit will automatically read your `requirements.txt`, install dependencies, and publish your project on a public URL.
